# Consarck Employee Meal Ordering System – V1
Online-ready web app starter with Supabase PostgreSQL database.

## Setup
1. Create a Supabase project.
2. Open SQL Editor and run `supabase/schema.sql`.
3. Edit `config.js` with your Supabase project URL and anon key.
4. Serve the folder from a web server (not file://) and open `index.html`.
5. Create the first admin in Supabase Auth, then add the matching profile in `admin_profiles`.

This V1 contains Employee Login, meal ordering, and an Admin dashboard foundation.
